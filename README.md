# 📊 Gestor de Finanzas & Divisas Web

Proyecto desarrollado para la materia **Fundamentos de Programación Web** (Sección 2662V).

## 🚀 Funcionalidades
- **Gestión de balance:** Registro de ingresos y gastos con actualización de saldo en tiempo real.
- **Persistencia de datos:** Uso de `localStorage` para conservar la información del usuario en el navegador.
- **Consumo de API:** Consulta en tiempo real de tipos de cambio (USD, EUR, COP) usando `fetch()` asíncrono.
- **Diseño Responsive:** Adaptable a dispositivos móviles y de escritorio mediante CSS Grid y Flexbox.

## 🛠️ Tecnologías
- HTML5 Semántico
- CSS3 (Grid / Flexbox)
- JavaScript Vanilla ES6+ (Fetch API, Async/Await, LocalStorage)
